## Where did EMAIL_HOST=smtp.gmail.com come from?
    This value comes from Gmail's SMTP server configuration. SMTP stands for Simple Mail Transfer Protocol; it is a standard way for your backend to send emails.
    
    Want to send an email verification link after registration. If using Gmail to send those emails, configuration uses:
    EMAIL_HOST=smtp.gmail.com

    This value is not generated by ourselves. It is Gmail's server hostname.
    
## If later switch to another email provider 
    may need to change the hostname, port, and authentication settings.
